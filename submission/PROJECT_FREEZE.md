# CounterLab — reviewed project freeze

Release label: **CounterLab 0.1 — final quality review, one-adapter prototype**.
Review date: October 26, 2026. Publication remains a separate step.

## Included scope

- Local app with recorded evidence inspection, bounded human-designed paging
  experiments, source/claim audit, evaluations and downloadable replay packages.
- Explicit-consent Nebius Token Factory / NVIDIA Nemotron investigation paths.
  The latest source workflow checks committed predictions before execution,
  retains rejected attempts and verifies admitted numerical measurements.
- Restricted local Docker execution for live investigations. Read-only startup
  and standalone evidence replay need neither Docker nor provider credentials.
- Separate portable recorded-evidence interface, full source archive, licenses,
  locked dependencies, compiled normal interface and local verification tools.

The package is a working prototype for one reviewed paging adapter. It is not
an arbitrary-paper ingestion service. The source-v2 demonstration uses simulated
planning and actual numerical execution; its live model quality is unmeasured.
The frozen real-model evaluations show no established advantage over the contract
heuristic. Full report reproduction, general scientific reliability and the
asymptotic theorem remain unresolved. Original failures and scores are retained.

## Acceptance and reproducibility

The acceptance evidence is recorded in `submission/VALIDATION.md`; detailed local
logs and receipts are under `artifacts/freeze/20261026/` and
`artifacts/freeze/20261026-final-review/` and are not distributed.
The clean-install procedure is **README → Quick start** (the
earlier wording is preserved in DEVELOPMENT_LOG → Fresh installation). The full regression suite needs the explicitly installed pinned
reference fixture; ordinary recorded inspection does not.

The final quality-review release is written to
`artifacts/releases/counterlab-final-review-20261026/`. Its `release-summary.json`
identifies the exact source and judge ZIP hashes; `source-manifest.json` identifies
every distributed source file. The final acceptance receipt lives beside those
archives. These are consistency records, not independent signatures or proof
of scientific validity. No full upstream reference, private run history, API
credentials, virtual environments or installed frontend packages are bundled.

The preceding `counterlab-project-freeze-20261026` archives remain unchanged as
historical releases. Use the quality-review archive for the next source upload.
See `FINAL_PROJECT_REVIEW.md` for its improvements and bounded execution profile.

## What happens after freezing

Use this reviewed source for the GitHub, judge-access, video and submission work.
Do not overwrite a frozen archive. A later defect fix gets a new release and
focused validation, with any affected acceptance checks rerun. Do not silently
change frozen evaluation results or increase their claim scope.

The GitHub repository stays private until publication is explicitly authorized.
No model batch, paid service, public deployment or final submission is authorized
by this freeze. Remaining submission work is tracked in `PROJECT_COUNTDOWN.md`.
